# Android Projects Portfolio
- This repository showcases a collection of Android applications I've developed in Java. Each project highlights different aspects of Android development, including user interface design, lifecycle management, CRUD operations, and integration with Firebase.

## Project List
1. Admissionform 
A basic Android application for creating admission forms. This app includes input fields for personal details and a submission button.
2. Android_lifecycle
This project explores the Android activity lifecycle and demonstrates how activities behave under different states.
3. Application login 2
A login application that includes user authentication with basic login functionality. It includes both user input validation and navigation to a home screen.
4. Calculator
A functional calculator application that performs basic arithmetic operations. It features a simple user interface for quick calculations.
5. CRUDApplication
A CRUD application that allows users to Create, Read, Update, and Delete records. This app is ideal for managing data locally on the device.
6. DebitCard
An app that simulates debit card information entry and basic functionalities related to debit card management.
7. Fragments
Demonstrates the use of Android Fragments for creating responsive and reusable components within an app.
8. Greeting_Name
A simple app where users can enter their name and receive a personalized greeting message.
9. Login Application
Another version of the login application with enhanced features such as password validation and error handling.
10. loginPage
Basic login page design with input fields for username and password, with form validation.
11. MasterProject
A more comprehensive project that includes various functionalities. This is a combination of several features from the other projects.
12. Menu
This project demonstrates how to implement a menu in an Android app, including navigation to different sections of the app.
13. Musical_Instruments
An educational app that provides information on different musical instruments, including images and sound clips.
14. MyFirstApp
My initial project in Android development, focused on understanding the basics of Android Studio and the Java programming language.
15. NumberConverter
An app that allows users to convert numbers between different bases (e.g., binary to decimal).
16. Signup Page
A registration page with input validation for email, username, and password. It serves as a frontend for user sign-up functionality.
17. SplashScreen
This app demonstrates a splash screen, showing a brief introduction or logo before navigating to the main app content.
18. SportList
Displays a list of sports using a ListView, with each item linked to a detailed information page.
19. UploadImageSQLite
Allows users to upload images and save them in an SQLite database for offline access.
20. CRUDWITHFIREBASE
A CRUD application that connects to Firebase for data storage and retrieval, supporting Create, Read, Update, and Delete operations in a cloud-based database.
